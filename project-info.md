# Project Information

## Nama Project

Hoga-Hoga Roll Cake Parapat

## Jenis Project

Sistem Informasi Penjualan Berbasis Website

## Tujuan Project

Project ini dibuat untuk menyediakan informasi mengenai
Toko Hoga-Hoga Roll Cake Parapat dan produk yang tersedia.

Website juga digunakan sebagai media untuk membantu pelanggan
mendapatkan informasi produk, kontak, lokasi, dan informasi
lainnya mengenai toko.

## Fitur Utama

- Halaman Home
- Halaman About
- Halaman Products
- Informasi detail produk
- Informasi kontak
- Informasi lokasi toko
- Jam operasional
- Responsive website
- Pemesanan melalui WhatsApp

## Produk

Produk yang tersedia pada website:

1. Durian
2. Coklat Lumer Kacang
3. Nutella / Meises
4. Klepon Matcha Lumer
5. Abon Ayam

## Teknologi

Project menggunakan:

- WordPress
- HTML
- CSS
- JavaScript
- MySQL
- XAMPP
- GitHub

## Pengembangan

Project ini masih dapat dikembangkan dengan menambahkan
beberapa fitur seperti sistem pemesanan, manajemen produk,
manajemen stok, dashboard admin, dan laporan penjualan.
